# گزارش — قالب Typst

```
just report         # ساخت report/main.pdf
just report-watch   # ساخت پیوسته
```

## ساختار

| فایل | نقش |
| --- | --- |
| `main.typ` | محتوای گزارش؛ فقط همین فایل را پر کنید |
| `template/lib.typ` | پیاده‌سازی قالب |
| `template/colors.typ` | پالت رنگ (جای‌گذاری با پالت نهایی) |
| `template/util.typ` | ارقام فارسی و کمکی‌ها |
| `refs.bib` | مراجع (سبک IEEE) |
| `fonts/` | مربع + استعداد + Recursive + Vazirmatn |
| `tools/make-fonts.py` | ساخت فایل‌های Recursive از فونت متغیر اصلی |

## امکانات

- سرصفحهٔ هر صفحه: بخش جاری در سمت چپ، عنوان گزارش در سمت راست
- عنوان بزرگ در ابتدای هر بخش (بدون سرصفحه)
- فهرست مطالب
- شماره‌گذاری بخشی برای رابطه/شکل/جدول/کد با ارقام فارسی
- `codly` برای کد، `cetz` برای نمودار، `bibliography` برای ارجاع مقاله‌ها

## فونت‌ها

فارسی: مربع با دو برش `Morabba Regular.ttf` و `Morabba Heavy.ttf` (یک خانواده با
نام `Morabba`). تایپست وزن ۴۰۰ تا ۶۰۰ را به Regular و ۷۰۰ تا ۹۰۰ را به Heavy
می‌رساند و وزن میانی وجود ندارد؛ چون Heavy برای متن و عنوان بیش از حد سیاه است،
کل گزارش روی Regular می‌ماند و عنوان‌ها با اندازه و رنگ از متن جدا می‌شوند:

| ثابت در `lib.typ` | مقدار | اثر |
| --- | --- | --- |
| `display-weight` | ۴۰۰ | عنوان گزارش، سر بخش، تیتر سطح دو |
| `strong-weight` | ۶۰۰ | تأکید، سر ستون جدول، سرصفحه (فارسی Regular می‌ماند، لاتین نیم‌سیاه می‌شود) |

### عوض‌کردن فونت فارسی

`Estedad[wght].ttf` هم در `fonts/` هست: فونت متغیر و آزاد با محور وزن کامل
۱۰۰ تا ۹۰۰. برای جای‌گزینی فقط سه خط اول `template/lib.typ` عوض می‌شود:

```typst
#let fa-family = "Estedad"
#let display-weight = 700
#let strong-weight = 700
```

چون استعداد همهٔ وزن‌ها را دارد، این بار وزن ۷۰۰ واقعاً نیم‌سیاه می‌دهد و
عنوان‌ها بدون دستکاری دیگری سیاه‌تر از متن می‌شوند. هر فونت فارسی دیگری هم که
در `fonts/` بگذارید با همین یک خط سوار می‌شود؛ فقط اگر وزن متغیر نداشت، دو عدد
پایین را با برش‌های موجودش هماهنگ کنید.

لاتین: فونت متغیر `Recursive_VF_1.085.ttf`. در هر پشتهٔ فونت، Recursive جلوتر
از فونت فارسی می‌آید تا لاتینِ داخل جملهٔ فارسی از Recursive و با همان وزن
درخواستی بیاید. `Vazirmatn[wght].ttf` فقط نقش پشتیبان پوشش نویسه را دارد.

تنها استثنا فونت کد است: حالت مونواسپیس روی محور `MONO` قرار دارد و تایپست فقط
وزن و سبک را می‌تواند درخواست کند، پس این سه فایل از همان فونت متغیر ساخته شده‌اند:

```
python3 tools/make-fonts.py <Recursive_VF.ttf> fonts/
```

## کمکی‌های نگارش

```typst
#en[English text]              // متن انگلیسی درون خط
#note[...]                     // جعبهٔ یادداشت
#warn(title: [هشدار])[...]     // جعبهٔ هشدار
#diagram(caption: [...], label-name: "fig-x", { import cetz.draw: *; ... })
```

ارجاع‌ها: `@eq-bellman`، `@fig-arch`، `@tbl-hparams`، `@code-train`، `@mnih2013dqn`
(پیشوند «رابطهٔ/شکل/جدول/کد» خودکار اضافه می‌شود).
